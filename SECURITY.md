# Security Policy

## Supported Versions

We provide security updates and patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of Mythos Agent, our autonomous agents, and scanning scaffolds seriously.

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a vulnerability, please report it privately:

1. **GitHub Private Vulnerability Reporting (Preferred):** Go to the repository's **Security** tab, click **Advisories**, and then click **Report a vulnerability**.
2. **Email Disclosure:** Send an encrypted or confidential email to `security@mythosagent.dev` or the maintainer at `kaype8996@gmail.com`.

### What to Include

Please provide:
- A descriptive summary of the vulnerability.
- Step-by-step reproduction instructions or a minimal proof of concept (PoC).
- Any affected components (e.g. LLM providers, sandbox executor, MCP server, tool bridge).
- Potential impact and threat assessment.

### Response Timeline

- **Initial Acknowledgment:** Within 48 hours.
- **Triage & Status Update:** Within 5 business days.
- **Fix & Coordinated Disclosure:** We aim to release a patch within 14–30 days depending on severity.
